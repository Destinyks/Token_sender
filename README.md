# Web3 Token Sender (Node.js)

A simple Node.js script for sending native tokens on Web3 networks (ETH / MATIC / BNB, etc.)

## 📦 Stack
- Node.js 18+
- ethers.js v6

## 📥 Inputs
- Sender's Private Key
- Recipient's Public Key
- Transfer Amount

## 🚀 Installation

```bash
git clone https://https://github.com/Destinyks/Token_sender
cd Token_sender
npm install
